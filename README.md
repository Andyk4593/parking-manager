# PARKING MANAGER

Казуальная web-игра на одного игрока: четыре шлагбаума, пятиминутная смена, интерактивное обучение и лёгкая 16-bit музыка. ПК, горизонтальный экран, мышь / сенсор и клавиши 1–4.

## Играть локально

Откройте `index.html` в Chrome или Edge. Установка и интернет не нужны. Для полного экрана используйте кнопку в игре или F11.

## Включить GitHub Pages

Готовый сайт уже находится **в корне ветки main**.

1. В репозитории откройте **Settings → Pages**.
2. Выберите **Deploy from a branch**, ветку **main**, папку **/(root)**.
3. Нажмите **Save** и после развёртывания откройте **Visit site**.

Pages включается владельцем репозитория. Серверной части и GitHub Actions для сборки не требуется. `.nojekyll` и относительные пути включены.

## Изменить и пересобрать

Исходники игры — `web/`. Понадобятся Node.js 22+ и pnpm; версия pnpm зафиксирована в package.json.

```powershell
pnpm install --frozen-lockfile
pnpm run build:pages
```

`build:pages` обновляет сайт в корне репозитория. После этого закоммитьте изменённые исходники и готовые файлы. Для отдельного локального превью:

```powershell
pnpm run build:web
pnpm start
```

## Проверки и документация

```powershell
pnpm test
pnpm run test:web-ui
pnpm run test:web-balance
pnpm run test:browsers
```

Для UI-тестов нужен runtime Electron (`pnpm run setup:runtime` при необходимости); последний набор использует установленные Chrome и Edge. Тестовые профили и результаты исключены из Git.
