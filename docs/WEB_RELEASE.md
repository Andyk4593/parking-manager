# PARKING MANAGER — web 1.1

> В Git-репозитории готовая игра лежит в корне (`index.html`), сборка для Pages — `pnpm run build:pages`. Инструкции с `site/` ниже относятся к ZIP-поставке.

Готовая игра для ПК, горизонтальный экран. Смена — до пяти минут или до потери трёх жизней. Для распакованной игры установка и интернет не нужны.

## Запуск

1. Распакуйте архив полностью, сохранив `assets` рядом с `index.html`.
2. Откройте `site/index.html` в Chrome / Edge. В отдельном архиве GitHub Pages файл находится сразу в корне, в исходниках — `web-dist/index.html`.
3. Нажмите «На весь экран» или F11, введите ник и нажмите «Участвовать».
4. Пройдите обучение; его можно пропустить или повторить из меню.

Браузер требует действие пользователя для звука и полного экрана. Во встроенных браузерах fullscreen может быть ограничен; используйте отдельную вкладку Chrome / Edge.

## Правила и управление

- Шлагбаумы сверху вниз: мышь / тап, **1–4** и **NumPad 1–4**.
- Импульс **0,65 с**, автозакрытие. Удержание не продлевает его; допущенная машина освобождает створ.
- Белый номер: проезд **+5**, столкновение **−1 жизнь**. Чёрный: проезд **−15**, закрытые ворота — взрыв без потерь. Цвет кузова значения не имеет.
- Номер сначала виден сразу; с ускорением появляется позже, к финалу с середины пути.
- **Esc** — пауза / продолжение. Уход из вкладки ставит игру на паузу. Рестарт доступен в паузе и результате.
- **Музыка** выключает фон; **Звук** выключает всё аудио. Выбор запоминается. На паузе и в автоигре фон не играет.
- После **30 секунд** без взаимодействия в меню / результате запускается автоигра. Нажатие возвращает ввод ника. Игра, обучение и пауза не прерываются.

## Личный результат

Для каждого ника сохраняются лучший и последний завершённые результаты в текущем браузере. Регистрации, общего рейтинга, сетевой отправки и аналитики нет. Ник — до 20 символов, регистр учитывается. Хранятся до 100 последних ников.

Очистка данных браузера удаляет рекорды. Другой браузер, адрес, порт или путь локального файла могут иметь отдельное хранилище. При запрете записи игра работает и сообщает о сохранении только до закрытия страницы. Учебные и демонстрационные очки не сохраняются.

## GitHub Pages

Папка `site` и архив `ParkingManager-GitHub-Pages.zip` содержат статический сайт; серверная часть и сборка на GitHub не требуются.

1. Распакуйте **содержимое** архива GitHub Pages в корень выбранного репозитория. `index.html`, `game.js`, CSS, `.nojekyll` и `assets` — на одном уровне.
2. **Settings → Pages → Build and deployment → Source → Deploy from a branch**.
3. Выберите **main**, **/(root)**, сохраните. Для `/docs` поместите туда весь сайт и выберите эту папку.
4. После публикации откройте **Visit site** и проверьте `https://<логин>.github.io/<репозиторий>/`.

Пути относительные; подкаталог проверен локально. `.nojekyll` отключает обработку Jekyll. Инструкция сверена с [GitHub Docs](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site) 16.09.2026.

Сайт **не опубликован**: пользователь размещает его в своём репозитории. Первая загрузка с Pages требует интернета. Надёжный автономный запуск — распакованный `index.html`; Service Worker / офлайн-кэш сайта не добавляли.

## Разработка и проверки

Исходники — `source/web/`, production — `source/web-dist/`. SVG / DOM, независимая JS-модель, Web Audio. Музыка — оригинальная 16-тактовая мелодия 92 BPM, синтезируется локально. Шрифт и лицензия включены; внешних записей и CDN нет.

Для разработки: Node.js 22+ и pnpm, версия в package.json. Из папки исходников:

```powershell
pnpm install --frozen-lockfile
pnpm run build:web
pnpm start
```

Превью — `http://127.0.0.1:4177/`. Другой порт: `node scripts/serve-web.mjs 4180`.

```powershell
pnpm test
pnpm run test:web-ui
pnpm run test:web-balance
pnpm run test:browsers
```

UI-тесты используют отдельный `web-test/` и скрытый Chromium из Electron. При отсутствии runtime: `pnpm run setup:runtime`. Production не содержит тестовых методов даже с `?test=1`. Последняя команда требует установленных Chrome / Edge и запускает изолированные профили без окна. Данные тестов в `output/` / `test-output/` не входят в поставку.

Для повторной упаковки после проверок: `python scripts/package-web.py`. Скрипт использует только разрешённый список исходников и готовый сайт.

Исторические Windows-модули и 20 unit-тестов оставлены в исходниках, но не входят в web-бандл. Старые инструкции — [[LEGACY_WINDOWS]]. EXE в этой поставке нет.
