# Web 1.1 — проверка финальной поставки

Дата: 16.09.2026. Итерация 10. Статус: **готово к пользовательскому плейтесту**, публикация не выполнялась.

## Что добавлено

Лёгкая оригинальная музыка 92 BPM с отдельным выключением; ник; личные лучший / последний результаты; автоигра после 30 с ожидания; готовый статический сайт. Кривая сложности итерации 9 сохранена по пожеланию Андрея. Production не содержит панели разработчика и тестовых методов.

Браузерные автоматические тесты выполнялись в скрытом Chromium / headless Chrome и Edge, с отдельными профилями. Проверены Fullscreen API, настоящий ввод на учебном шлагбауме, +5, пропуск обучения, пауза, три реальные аварии, результат, reload и память настроек. Во встроенной вкладке Codex дополнительно проверены меню, ввод ника, обучение, пауза и возврат. Полноэкранный вывод встроенного браузера не считается приёмкой физического экрана.

Автоигра: фактическое ожидание **30.436 с**. Демонстрационные результаты исключены из сохранения, первый тап / клавиша только возвращает меню. Игра, обучение, пауза и скрытая вкладка не переводятся в демо.

Музыка: оригинальная петля около 41,74 с, **920348** отсчётов, RMS исходного сигнала **0.0304**, пик **0.1396**, gain воспроизведения 0,5. Нет клиппинга и скачка на стыке. Проверены один источник после повторных рестартов, выключение фона отдельно от эффектов, остановка на паузе / фоне, запоминание. Эти числовые проверки не заменяют прослушивание на реальных динамиках.

Ускоренный прогон всей смены: 9027 шагов рендера, p95 **0.40 мс**. Реальная шестисекундная выборка: **50.2 FPS**, p95 кадра **33.4 мс**. Это текущий ПК, не доказательство минимальных системных требований или длительной нагрузки.

Баланс: точная политика прошла 60/60 смен с тремя жизнями; медиана 1405 очков. Спам четырёх ворот — медиана 45,77 с / 30 очков. Модель ограниченного внимания — 272,48 с / 1122,5 очка. Это синтетические политики, не статистика людей.

## Состав и воспроизведение

Исходники, тесты, локальные ресурсы и инструкции включены. Production и тестовый бандл разделены: `web-dist` / `web-test`; второй не поставляется. Упаковщик `scripts/package-web.py` проверяет результаты, состав, каждый байт в ZIP, CRC и SHA256. Данные сессий, `leaderboard.json`, профили, логи, тестовые output, node_modules и EXE исключены.
