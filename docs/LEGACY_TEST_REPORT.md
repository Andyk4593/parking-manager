# Проверка PARKING MANAGER 1.0.0

Дата: 10 сентября 2026. Статус: программные проверки пройдены; физический киоск и человеческий баланс не приняты.

## Среда

- Windows 11 Home x64, сборка ОС 26200; GPU UHD630 / GTX1050Ti. Конкретный адаптер рендера не измерялся.
- Node 24.19.0; Phaser 3.90.0; Electron 44.3.0; Electron Builder 26.15.3; Playwright 1.62.1.
- Игровое поле 1920×1080. Тесты интерфейса: CSS 1920×1080 и 1366×768. На физическом экране Windows с масштабом 125% полноэкранное окно сообщило CSS 1536×864, ровно размер `screen`; внутреннее поле масштабировалось с сохранением 16:9.

## Производительность

10 секунд измерения через `requestAnimationFrame` в Electron на текущем ПК: 601 кадр за 10,007 с; около **60 FPS**; средний интервал **16,65 мс**, 95-й процентиль **16,8 мс**. Сценарий начинался с восьми машин и поздней скорости. Это короткий замер рендера на данном ПК, а не длительный нагрузочный тест всех киосков и не замер задержки сенсора.

## Сложность

По 30 фиксированных seeds на каждый агент. Агент видит цвет без ошибок; задержка применяется к каждой машине; перемещение руки между полосами не моделируется.

| Задержка | Минимум | Медиана | Максимум |
|---|---:|---:|---:|
| 0 мс | 573 с | 584 с | 592 с |
| 200 мс | 536 с | 537 с | 538 с |
| 300 мс | 454 с | 455 с | 458 с |
| 400 мс | 263 с | 264 с | 268 с |

Отдельный тест подтверждает завершение на 600 с при оставшихся жизнях. Нельзя считать эти числа измерением человеческой реакции, сложности или «веселья». Кривая — кандидат для полевого теста.

## Визуальный просмотр

Просмотрены снимки стартового экрана, игрового поля, штрафа, водителя, взрыва, результата, демо и масштаба 1366×768. HUD не перекрывает четыре полосы; номера 1–4 совпадают с порядком сверху вниз. Финальные белые и чёрные номера читаются отдельно от цвета кузова. Постановочные кадры используют фикстуры; их нельзя считать реальной игрой человека.

## Найденное и исправленное

- Тест детерминизма сравнивал идентичность RNG-функций вместо состояния — исправлен на сериализуемое состояние.
- Цифровой режим экранной клавиатуры теперь выводит полный ряд 0–9.
- После визуального просмотра аварийная машина смещена до самого шлагбаума.
- Визуальные QA-фикстуры очищают эффекты предыдущих сценариев.
- Playwright `_electron.launch` не подключался к NSIS-оболочке; portable-тест запускает EXE как обычную программу и подключается через локальный CDP. Команда `Browser.getWindowForTarget` в этой версии Electron не поддерживается; полноэкранный режим проверен по совпадению размеров окна и экрана и скриншоту.

## Что остаётся проверить физически

1. Четыре зоны на конкретном сенсорном экране: точность, задержка, два одновременных касания, отсутствие паразитных тапов.
2. Читаемость номера на рабочем расстоянии, при освещении площадки и масштабе Windows 100–200%.
3. Слышимость и комфорт громкости через реальные динамики; звук фактически синтезируется, слуховая приёмка человеком ещё нужна.
4. 10–15 игроков разного опыта: понимание чёрных номеров, отсутствие выигрышной стратегии спама, ощущение роста сложности.
5. Целевой киоск / Windows 10, запуск с флешки, политика SmartScreen, права папки, длительная работа и возобновление после сна. Файл EXE не подписан коммерческим сертификатом.
