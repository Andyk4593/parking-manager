## Сохранённые продуктовые решения
- Пользователь выбрал импульс 0,65 с и жёсткий предел 10:00. Не заменять на переключатель открытия / закрытия без новой задачи.
- Визуально открытые ворота пропускают достигающие их машины: не вводить невидимую блокировку «одна машина за импульс».
- Без очков за остановку чёрной машины; штраф может сделать счёт отрицательным.
- Рейтинг хранит лучший результат ника, не все попытки; публично показываются максимум десять записей.
- Исходная память о железе использована только как ориентир; Windows x64 и GPU проверены заново. Никакие решения других игровых проектов не перенесены в MVP.
