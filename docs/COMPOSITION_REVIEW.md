# Композиция web-версии

## Изменение
Сделан самостоятельный браузерный макет `design/composition/index.html`. Основная игровая версия пока не менялась. Экран рассчитан на ПК 16:9; небо и перспектива, уменьшающая дальние машины, отсутствуют. Геометрия с фиксированным высоким видом сбоку-сверху, горизонтальное движение в будущем остаётся слева направо.

В плотном кадре 8 машин пяти типов: седан, кроссовер, минивэн, грузовичок и кабриолет. Белые и чёрные кузова преобладают; цвет кузова не обозначает допуск. Две стрелы подняты, две закрыты. Палитра: зелёный #006F3D, светлый зелёный #2E9563, асфальт #737C7D, тёмный #14372B, светлый #F4F0D9, мягкий зелёный #BAE3B3. Цифры и заголовок — локальный Press Start 2P, служебные подписи — Arial.

## Размеры и читаемость
- Полосы по 190 px, одинаковый масштаб объектов на всех полосах. Плашка 206×54 px находится под своей машиной; короткий указатель связывает её с кузовом.
- Цифры номера 40 px вместо прежних 16 px при разрешении 1920×1080: увеличение 2,5×. В 1366×768 — около 28,4 px.
- Зона каждого шлагбаума 210×178 px, в 1366×768 — около 149×127 px. Номер клавиши расположен внутри этой зоны.
- Основной кадр содержит шесть видимых номеров и два ещё скрытых. Отдельный переключатель раскрывает все восемь для проверки плотности; это инструмент просмотра, не игровая механика.

## Свежая проверка
Команда из корня исходников: `node scripts/check-composition.mjs`. Использует уже установленные Playwright и Chromium из Electron, скрытое окно, обычные HTML/CSS/JS без Node API в странице. Проверены точные CSS viewport 1920×1080 и 1366×768. Снимки сохранены в CSS-пикселях, независимо от масштаба Windows.

Результат: PASS. Проверено наличие 8 машин и 5 кузовов, локального шрифта, четырёх зон шлагбаумов. Все восемь плашек помещаются в своих полосах, не пересекаются друг с другом и зонами нажатия. Экран не обрезан, цифры не мельче 28 px. Переключатель плотности показывает восемь номеров. Не обнаружено ошибок страницы и внешних HTTP-запросов. Снимки в обоих размерах и кадр со всеми номерами просмотрены визуально. Дополнительно открыта поставляемая копия через localhost в браузере Codex: загрузка страницы и переключение шести номеров на восемь подтверждены.

## Вывод и границы
Композиция пригодна для следующего прототипа: номера, машины и целевые области разделены. Проверка ограничена статичными положениями; она не доказывает отсутствие перекрытий на всём пути движущихся машин. Баланс, времена реакции, столкновения, палец обучения, проигрыш / рестарт и раскрытие номеров в зависимости от сложности ещё предстоит реализовать. Макет не сохраняет результаты, не обращается к рейтингу и не содержит данных сессий. Проверка касаний на физическом киоске и удобства с реального расстояния остаётся открытой.

Следующий шаг — итерация 7: одна рабочая полоса в браузере с проверкой своевременного ввода и совпадения подъёма стрелы с фактическим проездом. После переноса графики в игровой рендерер повторить визуальную проверку.
