# Одна рабочая полоса

## Результат
Плавное движение всех пяти типов машин, крупная плашка своей машины, порог раскрытия 0–50% пути. Параметры скорости и раскрытия фиксируются при появлении машины. В начале путь до ворот занимает 4,8 с, в конце 1,55 с; промежуточные опорные значения 4,5 / 3,5 / 2,8 / 2,0 с. Это кандидат кривой для последующего четырёхполосного баланса.

Физическое пересечение ворот определяет исход; сам тап очки не выдаёт. Импульс 0,65 с включает подъём 0,12 с; допустимое окно пропуска начинается после подъёма и кончается до завершения импульса. Опускание 0,12 с, затем восстановление 0,16 с. Если допущенная машина ещё занимает створ, стрела ждёт её заднюю часть; ввод остаётся заблокирован до полного цикла. Следующая машина в прототипе появляется только после ухода предыдущей. Пропущенная машина продолжает освобождать створ и при завершении смены по таймеру.

Добавлены белый +5 / столкновение −1 жизнь, чёрный −15 / взрыв, базовые водитель с кулаком, дым, звуки и сообщения. Третья потеря жизни завершает смену после короткого эффекта. Есть пауза, результат, чистый рестарт и предел 300 игровых секунд; полное обучение и итоговый интерфейс остаются итерацией 8.

## Архитектурное решение
Для web сохранена принятая SVG-графика; логика отдельно в `web/src/lane-model.mjs`, отображение и ввод — в `app.mjs`, графика — в `art.mjs`. Это сохраняет ракурс без повторного переноса в Phaser и даёт лёгкую автономную сборку. DOM-плашки не перехватывают ввод и остаются в полосе; у ворот их положение ограничено, чтобы не закрывать зону нажатия. Связь с машиной сохраняет указатель. Для этой итерации один автомобиль, проверка полной плотности — в итерации 9.
