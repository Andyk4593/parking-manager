# PARKING MANAGER

Актуальный web-прототип, итерация 9: **[README_WEB.md](README_WEB.md)**. Запуск — `web-dist/index.html`. Ниже сохранена инструкция прежней Windows-версии 1.0; её десятиминутные правила не относятся к новому web-прототипу.

Автономная однопользовательская аркада для Windows 10/11 x64. Игровая сцена 1920×1080, сенсор и клавиши 1–4. Установка и интернет для игры не нужны.

## Запуск готовой игры

1. Распакуйте архив в обычную папку, например `Документы\ParkingManager`.
2. Дважды нажмите `ParkingManager.exe`. Игра сразу откроется на весь экран. Первое открытие может занять несколько секунд: внутри EXE распаковывается встроенный движок.
3. Введите ник физической или экранной клавиатурой и нажмите **«Участвовать»**.

Для запуска достаточно самого EXE. Рейтинг создаётся автоматически рядом с ним. Запускайте EXE из распакованной папки, а не из окна ZIP-архива. Приложение не требует Node.js, отдельного браузера, WebView2, административных прав или установки пакетов. Сборка не подписана коммерческим сертификатом; реакция Windows SmartScreen зависит от настроек компьютера.

## Управление и правила

| Действие | Управление |
|---|---|
| Открыть шлагбаум сверху вниз | Тап по зоне шлагбаума, клавиши **1–4** или NumPad **1–4** |
| Пауза / продолжить | Кнопка паузы или **Esc** |
| Звук | Кнопка с нотой справа сверху |
| Полный экран / окно | **F11**; также кнопка в меню паузы |
| Выход | «Выйти из игры» на стартовом экране или **Alt+F4** |

- Открытие длится **0,65 с**, затем **0,16 с** восстановления. Удержание клавиши и повторные нажатия во время восстановления не продлевают открытие.
- Машины приближаются скачками. Номер становится читаемым и мигает в последней позиции. **Цвет кузова не определяет допуск.**
- Белый номер: пропустите машину и получите **+5**. У закрытого шлагбаума машина сталкивается, водитель машет кулаком, вы теряете **1 жизнь**.
- Чёрный номер: оставьте шлагбаум закрытым — машина взорвётся, потерь и награды нет. Пропустите — получите **−15**, машина уедет с пробуксовкой и дымом. Счёт может быть отрицательным.
- Чёрных машин не более 10% от сгенерированного потока, первые девять всегда белые. Всего пять видов кузова; белые и чёрные преобладают.
- После трёх потерянных жизней смена заканчивается. На **10:00** смена завершается с сохранением результата даже при оставшихся жизнях. На паузе время не идёт.
- После 30 секунд без действий на стартовом или итоговом экране включается автоигра. Тап или клавиша возвращает ввод ника. Демо не пишет рекорды и не воспроизводит звуки.
- Звук активируется первым нажатием. Есть эффекты открытия, успеха, столкновения, штрафа, взрыва, старта и завершения.

## Перенос рейтинга

Закройте игру и скопируйте **`leaderboard.json`** из папки с EXE в папку с EXE на другом компьютере. В нём хранится топ-10, лучший результат каждого ника; регистр букв не создаёт нового игрока.

Если файла нет, игра создаёт его с результатами: Вася — 90, Петя — 60, Толик — 30. Повреждённый файл по возможности переименовывается в `leaderboard.json.corrupt-<время>`, затем создаётся начальный рейтинг. Запись использует временный файл и атомарное переименование. При невозможности записи появится сообщение: перенесите игру в папку, куда можно записывать. В папке только для чтения никакое приложение не может создать постоянный файл; до выхода рейтинг остаётся в памяти.

Не подменяйте файл во время открытой игры: текущий процесс уже держит рейтинг в памяти. Файл открыт для ручной правки; защиты от подмены результатов в MVP нет.

## Разработка из исходников

Папка `source` в поставке содержит код и предсобранную веб-версию `dist`. Ниже команды выполняются **из папки source**. Для разработки: Node.js 24+, pnpm 11.19.0, Windows x64. Для первой установки инструментов и зависимостей нужен интернет; готовая игра полностью автономна.

```powershell
npm install --global pnpm@11.19.0
pnpm install --frozen-lockfile
pnpm run setup:runtime
pnpm test
pnpm run build
pnpm start
```

```powershell
# Интеграция в настоящем Electron, фикстуры и снимки экрана
pnpm run test:ui
# Реальные 30 секунд ожидания, эмуляция двух касаний, NumPad, замер кадров
pnpm run test:extended
# 120 синтетических прогонов сложности
pnpm run test:balance
# Новая portable Windows-сборка: release/ParkingManager.exe
pnpm run package
# Проверка EXE из двух отдельных папок с русскими именами
node tests/portable.mjs
```

Для проверки уже готового EXE можно передать его путь: `node tests/portable.mjs "..\ParkingManager.exe"`.

Веб-предпросмотр: `pnpm run preview`, затем открыть `http://127.0.0.1:4173`. В нём используется хранилище браузера; переносимый JSON реализован именно в Windows-приложении. Предсобранную `dist/index.html` также можно открыть локально для ознакомления.

## Где менять игру

| Файл | Назначение |
|---|---|
| `src/model.mjs` | Правила, очки, генератор, жизни, предел смены; `difficulty()` — кривая сложности |
| `src/renderer.mjs` | Оригинальные пиксельные машины, дорога, ворота, водитель, дым, взрыв |
| `src/app.mjs`, `src/style.css`, `public/index.html` | Экраны, события ввода, HUD, клавиатура, демо |
| `src/audio.mjs` | Синтез звуков через Web Audio |
| `electron/main.cjs`, `electron/preload.cjs` | Локальное окно и ограниченный мост к файлам |
| `electron/leaderboard.cjs` | Проверка и запись рейтинга |
| `tests` | Unit, интеграционные тесты, portable и баланс |
| `ROADMAP.md`, `docs/DECISIONS_ARCHIVE.md` | Краткий контекст и архив решений для Obsidian |

Рендер отделён от симуляции. Все изображения, шрифт, движок и звук локальные; CDN и сетевых вызовов нет. Electron блокирует внешние HTTP(S)/WebSocket-запросы, навигацию и разрешения. Node отключён в странице, preload изолирован. Тестовый API доступен только в специальном запуске исходников; обычный EXE его не включает.

## Приёмка на киоске

Автоматические проверки и ограничения описаны в `TEST_REPORT.md`. Перед публичной эксплуатацией проверьте физический мультитач, задержку и точность сенсора по всем четырём полосам, NumLock / раскладку, громкость динамиков, масштаб Windows 100–200%, запуск с флешки и права записи. Баланс надо проверить на людях: результаты синтетических агентов не доказывают удобство или удовольствие от игры.
