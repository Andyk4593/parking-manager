# PARKING MANAGER — композиция web-версии

Итерация 6, 16.09.2026. Это статичный макет игрового экрана, не новая игровая сборка. Показатели счёта, времени и жизней приведены для оценки интерфейса.

Откройте `index.html` в браузере. Установка и интернет не нужны. Можно также разместить содержимое папки на статическом сервере: пути к ресурсам относительные.

При наведении мыши появляется панель просмотра внизу. «Проверить все номера» показывает плашки всех восьми машин для проверки плотности. «На весь экран» разворачивает макет; выход — Escape. Клавиши 1–4 и шлагбаумы в этой итерации обозначают будущие игровые зоны, но не запускают игру.

Кадр содержит четыре горизонтальные полосы, восемь машин пяти типов, два открытых и два закрытых шлагбаума. Высокий вид сбоку-сверху сохраняет одинаковый масштаб всех полос. В игровом примере некоторые номера ещё скрыты; переключатель всех номеров предназначен только для просмотра макета.

Локальный шрифт Press Start 2P распространяется по SIL Open Font License; текст лицензии в `assets/FONT-LICENSE.txt`. Геометрия дороги, машин и шлагбаумов создана в `scene.js`; графика SVG, плашки и интерфейс HTML/CSS. Внешних библиотек и сетевых ресурсов у макета нет.

Следующая итерация: одна игровая полоса, непрерывное движение, раскрытие номера от начала до середины пути в зависимости от сложности, подъём и автозакрытие шлагбаума.
